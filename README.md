# hygor.com.br

Meu portfólio: https://hygor.com.br

Página estática (HTML e CSS puros, sem build), com os projetos que mantenho em produção:

- [Haveres](https://haveres.app): controle de carteira de investimentos
- [HPR Print 3D](https://hprprint3d.hygor.com.br): vitrine e oficina da minha loja de impressão 3D
- [Pitwall](https://pitwall.hygor.com.br): engenheiro de corrida para ACC e iRacing

## Como publicar

Basta dar push na `main`. A VPS puxa este repositório a cada 5 minutos e serve a pasta
como está (Caddy, HTTPS automático).

## Estrutura

- `index.html`: a página inteira (estilos e script no próprio arquivo)
- `img/`: capturas de tela dos projetos (960×600, JPG)
