Como tudo isso roda

Um servidor só, organizado para que colocar um projeto novo no ar seja questão de minutos.

01 · Domínios

DNS

haveres.app e hygor.com.br apontam para a mesma VPS, um subdomínio por projeto.

02 · Entrada

Caddy

Proxy reverso com HTTPS automático. É o único serviço exposto à internet.

03 · Aplicações

Docker

Cada projeto no seu compose. Sites estáticos se atualizam sozinhos a cada push.

04 · Dados

Supabase

PostgreSQL gerenciado fora do servidor: trocar de máquina não arrisca nenhum dado.
