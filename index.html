Por trás

Como tudo isso roda

Os três projetos e esta página ficam num servidor só, organizados para que colocar um projeto novo no ar seja questão de minutos.

1 · Domínios

DNS

haveres.app e hygor.com.br apontam para a mesma VPS, com um subdomínio por projeto.

2 · Entrada

Caddy

Proxy reverso com HTTPS automático. É o único serviço exposto à internet.

3 · Aplicações

Docker

Cada projeto no seu próprio compose. Os sites estáticos se atualizam sozinhos a partir do GitHub.

4 · Dados

Supabase

PostgreSQL gerenciado, fora do servidor: trocar de máquina não coloca nenhum dado em risco.
